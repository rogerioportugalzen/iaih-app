# Iahii · app

Aula piloto jogável (v0.1). Arquivo único `index.html`, gerado e compactado a partir do projeto de design.

Cada envio para a branch `main` publica automaticamente em https://app.iahii.app pela automação em `.github/workflows/deploy.yml` (FTP da Hostinger, com os dados guardados nos segredos do repositório).
